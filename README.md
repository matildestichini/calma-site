# Site C'alma Home Spa

Site estático (uma página). Alojado no Netlify, com publicação automática a cada alteração neste repositório.

- `index.html` — página. Configuração (links da Fresha e do Facebook, número de WhatsApp, valores do P&L) no bloco `CALMA` no fim do ficheiro.
- `assets/fonts` — Black Mango (Regular e Bold).
- `assets/logos` — logótipos.
- `assets/photos` — fotografias reais da gravação. Ver `LEIA-ME.txt` para os nomes dos ficheiros.
